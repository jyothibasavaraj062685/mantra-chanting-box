# 🪔 Divya Mantra Chanting Box

A simple, kid-friendly Android & mobile web app that chants **Mantras**, **1-Paragraph Stotras**, **Ashtottara Namavalis**, and **Famous Aarti & Bhajan Songs** in a non-stop loop until you press **STOP**.

## Included Deities & Famous Chants
- **Om (`ॐ`)**: *Om.. Om.. Om..* (136.1 Hz Cosmic Chant), *Sarve Bhavantu Sukhinah*
- **Lord Ganapati**: *Vakratunda Mahakaya*, *Om Gam Ganapataye Namah*, *Jai Ganesh Jai Ganesh Deva*
- **Lord Shiva**: *Karpura Gauram Karunavataram*, *Om Namah Shivaya*, *Shivaya Parameshwaraya*
- **Gowri / Parvati**: *Sarva Mangala Mangalye*, *Om Sri Matre Namah*, *Ya Devi Sarva Bhuteshu*
- **Goddess Lakshmi**: *Namastestu Mahamaye*, *Om Jai Lakshmi Mata (Aarti)*
- **Lord Krishna**: *Vasudeva Sutam Devam*, *Achyutam Keshavam Krishna Damodaram*, *Shri Krishna Govinda Hare Murare*
- **Lord Vishnu**: *Shantakaram Bhujagashayanam*, *Om Jai Jagadish Hare (Aarti)*
- **Lord Hanuman**: *Manojavam Marutatulyavegam*, *Raghupati Raghava Raja Ram*
- **Sri Guru**: *Gurur Brahma Gurur Vishnu*, *Jaya Guru Omkara*
